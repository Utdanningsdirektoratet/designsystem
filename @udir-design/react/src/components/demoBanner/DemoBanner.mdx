# DemoBanner

`DemoBanner` brukes for å tydeliggjøre for sluttbrukeren at de er i en demoversjon av en applikasjon. Dette er viktig for å unngå at brukere fullfører prøver, undersøkelser eller lignende i demoversjonen ved en feil. Les mer om [bruksmønster for markering av demoversjoner](/docs/patterns-demoversjon-av-tjenester--docs).

**Passer til å**

- Markere at brukeren er i en demoversjon av en applikasjon der data ikke lagres

**Passer ikke til å**

- Markere hvilket utviklingsmiljø brukeren er i – bruk heller [`Tag` i `Header`](/docs/components-header--docs#utviklingsmilj%C3%B8)

## Slik bruker du DemoBanner

<Canvas of={DemoBannerStories.Preview} withToolbar />
<Controls of={DemoBannerStories.Preview} />

```tsx
import { DemoBanner } from '@udir-design/react';

<DemoBanner>
  <Header />
  {/* Innhold på siden */}
  <Footer />
</DemoBanner>;
```

## Tekst i DemoBanner

Hvis du trenger å tilpasse teksten i banneret, kan du overstyre standardteksten med `text`. Er teksten fast, kan du også sette den i ditt eget stilark, se [Kompatibilitet](#kompatibilitet).

## Språkstøtte

Komponenten har innebygget støtte for bokmål, nynorsk og engelsk. [Slik støtter du flere språk](/docs/components-språkstøtte--docs).

Følgende tekstvariabler er tilgjengelige for overstyring:

## Innhold på siden

Vær oppmerksom på at den øverste delen av `DemoBanner` legges under headeren med ekstra margin for å unngå overlapping med øvrig innhold på siden. Den nederste delen legges over annet innhold. Sørg for at det ikke er viktig innhold nederst på siden som kan bli dekket av banneret.

## Kompatibilitet

### Server-side rendering og Content Security Policy

`text` settes med JavaScript etter at siden er lastet. Ved server-side rendering vises derfor standardteksten til JavaScript har lastet. Er teksten fast, kan du heller sette den i ditt eget stilark. Det virker også med en streng Content Security Policy:

```css
.testmiljo {
  --udsc-demo-banner-text: 'Testmiljø';
}
```

```tsx
<DemoBanner className="testmiljo">…</DemoBanner>
```

Teksten er en CSS-streng, så den må stå i anførselstegn. Les mer om [server-side rendering og Content Security Policy](/docs/components-server-side-rendering-og-csp--docs).
